# NIDAR AirMouse GCS
Ground Control Station for an autonomous GPS-denied indoor rescue drone (NIDAR Track 1). Runs on one laptop, fully OFFLINE.

## Hard competition rules (never violate)
- Operator can ONLY: START mission, ABORT mission. NO other controls (no manual flight, waypoints, click-to-tag, map editing). Anything else = manual intervention = penalty.
- Map + survivor data are generated by the drone and displayed LIVE during flight. No post-flight processing.
- No internet: no CDN, no online fonts, no map tiles, no external APIs. Bundle all assets.
- Live camera feed must be shown inside the GCS (no separate video device).
- Max flight time 30:00; faster is better, so show a prominent mission timer.
- Arena <= 15x15 m, grid-based, rooms 2x2 m, corridors >= 1 m. Cell size is config (config.json).
- Up to 6 survivors, each tagged with a grid cell label (e.g. "C7") on the map.
- Must display: mission status, live video, live 2D map, corridors/rooms (best effort), survivor cell + marker, drone position, mission progress/completion.
- Failsafe chips: LOW BATTERY, LINK LOSS, GEOFENCE, ABORT, RECALL.

## Stack
Backend: Python 3.11+, FastAPI, uvicorn, numpy, pillow, opencv-python-headless, pydantic.
Frontend: React + Vite + TypeScript + Tailwind + zustand. Map = Canvas 2D only (no WebGL, no map libs). Fonts via @fontsource (bundled).
One command runs everything: `python run.py` (add --sim for simulator). Frontend production build is served by FastAPI.

## Architecture
drone-or-simulator --WS JSON--> /ingest (backend) --WS--> /ws (dashboard)
dashboard --{"cmd":"START"|"ABORT"}--> /ws --> backend --> forwarded to the drone over /ingest.
Video: drone/simulator serves MJPEG at config.video_url; dashboard uses <img>.
The simulator is just a drone-side client of /ingest. Real hardware replaces it later with ZERO dashboard changes.

## Coordinates
Arena frame in metres: (0,0) = arena bottom-left, x right, y up, yaw CCW from +x.
Cell label = column letter from floor(x/cell_size) (A..) + row number floor(y/cell_size)+1. Computed by the GCS, not the drone.

## Message contract (drone -> GCS, JSON)
telemetry @10Hz: {"type":"telemetry","t":unix_s,"pose":{"x":m,"y":m,"yaw":rad},"speed":m_s,"alt":m,"battery":{"v":V,"pct":0-100},"link":{"rssi":dBm,"latency_ms":n,"loss_pct":n}}
mission @2Hz and on change: {"type":"mission","state":"IDLE|PREFLIGHT|READY|EXPLORING|RETURNING|EXITED|ABORTED|FAILSAFE","elapsed_s":n,"explored_pct":n,"survivors_found":n,"distance_m":n}
map @2Hz: {"type":"map","res":0.1,"w":n,"h":n,"origin":{"x":m,"y":m},"data":"<base64 of zlib-compressed int8 row-major; -1 unknown, 0 free, 100 occupied>"}
path @1Hz: {"type":"path","trail":[[x,y],...],"plan":[[x,y],...]}
survivor on detection: {"type":"survivor","id":1-6,"x":m,"y":m,"conf":0-1,"t":elapsed_s,"snapshot":"<base64 jpeg, optional>"}
failsafe on change + 1Hz: {"type":"failsafe","low_battery":bool,"link_loss":bool,"geofence":bool,"abort":bool,"recall":bool}
preflight: {"type":"preflight","checks":{"link":bool,"video":bool,"map_stream":bool,"battery":bool,"sensors":bool,"failsafes":bool}}
event: {"type":"event","level":"info|warn|crit","msg":"..."}
GCS -> drone ONLY: {"cmd":"START"} or {"cmd":"ABORT"}
